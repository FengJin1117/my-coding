这道题比较适合用 **DP + 状态机**。关键点是：不能看到 `202` 就贪心替换，因为一次替换可能破坏一个已有的 `2026`，也可能把后面的 `202` 变成 `6`，从而新造出一个 `2026`。

例如样例 2：

```text
2026202202
= 2026 + 202 + 202
```

把最后一个 `202` 替换成 `6`：

```text
2026 + 202 + 6
= 20262026
```

最终有 `2` 个 `2026`。

### 1. 把操作理解成「扫描时有两个选择」

从左向右扫描原字符串。

走到位置 `i` 时：

* 不操作：保留 `s[i]`，相当于向最终字符串添加一个字符，`i += 1`
* 如果 `s[i:i+3] == "202"`：可以把它整体替换成一个 `6`，相当于向最终字符串添加字符 `6`，`i += 3`

所以实际上是在问：

> 用这两种方式生成最终字符串时，最多能产生多少次 `2026`？

问题是我们不需要真的保存整个最终字符串。为了判断新加入一个字符后是否形成 `2026`，只需要知道当前字符串末尾与 `"2026"` 匹配到了哪一步。

定义 4 个状态：

```text
0: 当前结尾什么也没匹配
1: 当前结尾是 "2"
2: 当前结尾是 "20"
3: 当前结尾是 "202"
```

如果当前状态是 `3`，再加入一个 `6`：

```text
202 + 6 -> 2026
```

答案 `+1`。

---

### 2. DP 定义

```text
dp[i][j]
```

表示：

> 已经处理完原字符串前 `i` 个字符，并且最终字符串当前处于匹配状态 `j` 时，最多获得多少个 `2026`。

每个位置做两种转移即可。

状态转换其实很小，可以直接预处理：

```text
状态0:
  +2 -> 1
  +0 -> 0
  +6 -> 0

状态1: "2"
  +2 -> 1
  +0 -> 2
  +6 -> 0

状态2: "20"
  +2 -> 3
  +0 -> 0
  +6 -> 0

状态3: "202"
  +2 -> 1
  +0 -> 2
  +6 -> 找到一个2026，答案+1，状态回到0
```

### 3. Python 代码

```python
s = input().strip()
n = len(s)

# trans[state][char] = (new_state, score_increment)
trans = {
    0: {
        '0': (0, 0),
        '2': (1, 0),
        '6': (0, 0),
    },
    1: {  # "2"
        '0': (2, 0),
        '2': (1, 0),
        '6': (0, 0),
    },
    2: {  # "20"
        '0': (0, 0),
        '2': (3, 0),
        '6': (0, 0),
    },
    3: {  # "202"
        '0': (2, 0),
        '2': (1, 0),
        '6': (0, 1),   # 形成 "2026"
    },
}

NEG = -10**9

# dp[i][state]
dp = [[NEG] * 4 for _ in range(n + 1)]
dp[0][0] = 0

for i in range(n):
    for state in range(4):
        if dp[i][state] == NEG:
            continue

        # 方案1：当前字符不替换，直接加入最终字符串
        new_state, add = trans[state][s[i]]
        dp[i + 1][new_state] = max(
            dp[i + 1][new_state],
            dp[i][state] + add
        )

        # 方案2：当前位置开始是 "202"，整体替换为 "6"
        if i + 2 < n and s[i:i + 3] == "202":
            new_state, add = trans[state]['6']
            dp[i + 3][new_state] = max(
                dp[i + 3][new_state],
                dp[i][state] + add
            )

print(max(dp[n]))
```

### 4. 为什么不能简单「遇到 202 就换」

因为 `202` 有两种价值：

```text
202 + 6
^^^^^^
已经可以构成 2026
```

此时把 `202` 换成 `6` 反而会破坏答案。

但：

```text
202 + 202
```

可以把后一个 `202` 换掉：

```text
202 + 6
= 2026
```

所以一个 `202` 到底应该**保留作为 `2026` 的前三位**，还是**替换成 `6` 作为 `2026` 的最后一位**，取决于前后文。这正是 DP 要解决的选择冲突。

时间复杂度只有：

$$
O(4n)=O(n)
$$

空间复杂度上面的写法是 \(O(n)\)，进一步使用滚动 DP 也可以降到 \(O(1)\)。
